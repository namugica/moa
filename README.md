# MOA

여행 계획부터 지출 기록과 투명한 비용 분할까지 이어지는 반응형 웹 프로토타입입니다.

## 실행

추가 의존성 설치 없이 저장소에서 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

`index.html`이 진입점입니다. JavaScript 모듈을 사용하므로 HTML 파일을 직접 여는 대신 HTTP 서버로 실행하세요.

## 구현한 기능

- 여행 생성: 여행지, 날짜, 동행 멤버 등록
- 날짜별 일정 추가·수정·삭제와 같은 날짜 안에서 순서 변경
- 계획 중 → 여행 중 → 여행 종료 상태 전환
- 일정 연결 또는 독립 지출 추가·수정·삭제
- 결제자와 실제 참여자를 구분한 원화 균등 분할
- 개인별 결제액·부담액·차액과 지출별 계산 과정
- 브라우저 localStorage 저장, 예시 여행, JSON 내보내기
- 모바일·데스크톱 화면

초기 화면은 실제 여행이 없는 상태입니다. ‘예시 여행 살펴보기’를 누르면 명시적으로 예시 데이터를 추가합니다. 일정을 지워도 그 일정에 연결된 지출은 독립 기록으로 보존합니다. 지출 합계에는 실제 지출만 포함되며 예상 비용은 별도로 표시합니다. 원 단위 나머지는 참여자 순서대로 배분합니다.

Node.js 18 이상에서:


## 범위와 데이터

서버·로그인·공동 편집·멤버 초대·공개 코스 검색 및 복사·사진 업로드·푸시 알림·실제 송금·외화 환산은 아직 구현하지 않았습니다. 분할 결과는 계산 참고용이며 송금 완료 현황을 의미하지 않습니다.

데이터는 현재 브라우저의 현재 주소(origin)에만 저장됩니다. 브라우저 데이터 삭제, 다른 기기 또는 다른 포트 사용 시 기존 여행이 나타나지 않을 수 있습니다. JSON 내보내기로 기록을 보관할 수 있지만 현재 버전에는 가져오기 기능이 없습니다. 실제 개인정보나 중요한 경비 기록을 보관하는 서비스로 배포하기 전에는 서버 저장·인증·복구 및 동기화 설계가 필요합니다.

데이터 구조는 `Trip`에 멤버, 일정, 지출을 별도로 두며, 지출은 선택적으로 일정에 연결됩니다. 실제 지출에는 결제 멤버 ID와 참여자별 부담 금액이 저장됩니다.
